# JM 桌面端

基于 [jmcomic](https://github.com/hect0x7/JMComic-Crawler-Python) 开源库 + PySide6 的
**禁漫天堂（JM Comic）桌面客户端**：在线搜索、在线阅读、批量下载、本地书架管理。

> ⚠️ 本应用仅限**年满 18 周岁**的成年人使用。
> 工具仅供个人学习与技术研究，所有内容版权归原作者及站点所有，请勿用于商业用途。

## 功能

- **主页分类**：分类按钮 + 排序按钮即点即加载，封面卡片墙 + 分页浏览。
- **搜索**：关键词 / 标签 / 作者 / 作品 / 人物 五种模式；排序；分页；
  直接输入漫画编号可跳过搜索直达详情页。
- **详情页**：封面、作者、标签（点击跳转搜索）、简介、章节列表、收藏。
  多章节本子支持勾选章节下载，或双击某章节直接从该话开始阅读。
- **阅读器**：在线 / 离线通用；**翻页**与**滚动**两种模式；三种缩放；
  章节切换；自动预取后续页面；图片缓存到本地。
  - **阅读进度记忆**：自动记录读到哪一话哪一页，下次在详情页点「▶ 继续阅读」直接回到原位；
    书架和收藏的封面卡片右下角也会显示进度角标（如 `第2话 5/30页`）。
- **下载**：多线程并发；进度显示；可取消 / 重试 / 断点续传（已存在的文件自动跳过）；
  自动保存封面与 `info.json` 元数据；下载后可离线阅读。
- **书架**：「下载」页以封面卡片墙展示所有已下载漫画（复用本地封面，不联网）；
  左键离线阅读，右键可打开文件夹 / 删除文件 / 导出。
- **导出**：书架右键可将已下载本子导出为 **CBZ**（zip 打包，漫画阅读器通用格式）
  或 **PDF**（img2pdf 无损嵌入原图），输出到 `下载目录/导出`。
- **收藏**：本地收藏夹，右键移除。
- **缓存管理**：封面 / 阅读缓存分别设上限，超限自动按「最久未访问」淘汰（LRU），
  也可一键手动清理（详见下文「缓存与数据」）。
- **设置**：主题、下载目录、接口类型、并发线程、重试次数、代理、自定义域名、账号登录、缓存上限。
- **一键打包发布**：生成一个只含程序代码、绝不含个人数据的最干净 zip，方便发给别人。

## 环境要求

- Windows / macOS / Linux
- Python 3.9+（已在 Python 3.14 上实测）

## 安装

```bash
pip install -r requirements.txt
```

依赖只有三个：`jmcomic`、`PySide6`、`img2pdf`（用于 PDF 导出）。

## 启动

- 双击 `启动JM桌面端.bat`（Windows，用无控制台窗口的方式启动），或
- 命令行运行：`python main.py`

启动脚本会自动探测 Python 解释器并检查依赖，缺依赖时会提示安装命令而不是闪退。

## 使用说明

1. 首次启动需确认年龄（仅一次）。
2. 在「主页」点分类翻，或在「搜索」页输入关键词 / 标签 / 作者 / 作品 / 人物，回车搜索。
3. 点击封面进入详情页 → 「在线阅读」或「下载本子」。
4. 下载进度在左侧「下载」页查看；下载完成后会以封面卡片出现在「已下载漫画」书架，
   点击即可离线阅读，右键可导出 CBZ / PDF。

### 阅读器：两种模式

| 模式 | 说明 | 默认缩放 |
| --- | --- | --- |
| 翻页 | 单页显示，整屏一张图 | 适应窗口 |
| 滚动 | 整章纵向连续滚动，**页间距为 0**，被裁断的跨页漫画可以无缝拼回 | 适配宽度 |

两种模式各自记住自己的默认缩放：来回切换不会把缩放搞乱，也不会跳回第一页。

### 阅读器操作

| 操作 | 功能 |
| --- | --- |
| ← → / 空格 / PgDn | 下一页（翻页模式）；滚动模式下为翻一屏 |
| PageUp | 上一页 |
| ↑ ↓ | 滚动模式：细滚动；翻页模式：等同翻页 |
| Home / End | 第一页 / 最后一页 |
| F | 切换为「适配宽度」 |
| Esc / 「← 返回」 | 返回上一级（阅读器 → 详情页 → 来源页） |
| 鼠标滚轮 | 正常滚动 |
| **鼠标中键** | **Chrome 风格自动滚动**：按一下中键进入自动滚动，鼠标往上/下离开中心点即按偏移量加速滚动，再点一下中键（或左键 / 滚轮 / 鼠标移出窗口）停止 |

### 设置项说明

| 设置 | 说明 |
| --- | --- |
| 主题 | 暗色 / 亮色，保存后立即切换 |
| 下载目录 | 下载与导出的落地位置 |
| 接口类型 | `api`=移动端接口（默认）；`html`=网页端接口 |
| 图片并发线程 | 同时下载图片的线程数，默认 4，网速快可调大 |
| 请求重试次数 | 单张图失败后的重试上限，默认 5 |
| HTTP 代理 | 网络受限时使用，如 `http://127.0.0.1:7890`，留空＝直连 |
| 自定义域名 | api 接口域名（逗号分隔），留空自动获取最新域名 |
| 账号 / 密码 | 可选。部分本子需要登录才能查看 / 下载 |
| 缓存上限 / 自动清理 | 见下文「缓存与数据」 |

## 缓存与数据

运行时生成的所有内容都在项目下的 `data/` 目录：

```
data/
├─ settings.json     # 设置（⚠️ 含账号密码）
├─ favorites.json    # 收藏
├─ progress.json     # 阅读进度
├─ covers/           # 封面缓存
├─ reader-cache/     # 阅读缓存（按 本子ID/章节ID 存放）
└─ app.log / error.log
```

**缓存策略**

- 阅读缓存是**按需逐页**下载的（当前页及后续若干页），不会因为打开一本就缓存整本。
- 封面缓存与阅读缓存各有容量上限，默认 **封面 500 MB / 阅读 2048 MB**，
  在「设置 → 缓存」里可改，填 `0` 表示不限制。
- 超限时按「最后访问时间」自动淘汰最久未使用的内容：
  **封面逐张删**（互相独立），**阅读缓存整本删**（避免删半本导致前几页命中、后几页重下）。
- 正在阅读、正在下载的本子会被跳过；最近 5 分钟内动过的缓存也不动。
- 手动清理只作用于上面两个缓存目录，**下载目录、收藏、阅读进度永远不会被碰**。
- 自动检查在启动 8 秒后跑一次，之后每小时一次（可在设置里关掉自动清理）。

> **想把程序发给别人**，不要直接拷整个项目文件夹（会带 settings.json 里的账号密码、
> 收藏与阅读记录）。用下面的「打包发布」。

## 打包发布

生成一个干净的 zip 包，别人解压后装个依赖就能跑。

- 双击 `打包发布.bat`，或
- 命令行：`python scripts/pack_release.py`

**打包规则（白名单式）**：只有明确列出的东西会进包 ——
`main.py`、`requirements.txt`、`README.md`、`启动JM桌面端.bat`、`app/` 下的源码。
其余一律不进，包括 `data/`（设置/收藏/进度/缓存/日志）、`下载/`、`__pycache__`、各种备份目录。

脚本还有一道**隐私哨兵**兜底：即使白名单被误改，`settings.json` / `favorites.json` /
`progress.json` / `*.json` / `*.log` 也会被直接拒绝，命中就整体中止打包。
打完会把 zip 读回来复检一遍，确认没有混入不该有的文件。

可选参数：

```bash
python scripts/pack_release.py --list       # 只列出会进包的文件，不生成 zip
python scripts/pack_release.py --out DIR    # 指定输出目录
python scripts/pack_release.py --no-open    # 打包后不自动打开输出文件夹
```

产物输出到项目同级的 `JM桌面端_发布/` 目录，形如 `JM桌面端_20260914.zip`，
解压后是一个 `JM桌面端` 文件夹，双击其中的 `启动JM桌面端.bat` 即可运行
（对方首次使用需先 `pip install -r requirements.txt`）。

## 常见问题

- **搜索 / 详情失败**：检查「设置 → 接口类型」，api 接口失败可切换 html 试一次；
  或填写代理 / 自定义域名后保存重试。
- **下载提示失败**：多为网络波动，点「重试」即可（已下载的图片不会重复下载）。
- **图片显示异常**：jmcomic 会自动处理图片解密；若某张失败，下一页再翻回来即重新加载。
- **滚动模式加载时画面跳动**：已通过读取图片头获取真实尺寸做精确占位解决；
  若仍遇到，多半是该章图片尺寸异常，切换一次缩放模式可强制重排。
- **磁盘占用变大**：到「设置 → 缓存」看占用，点「立即清理超额」或直接「清空封面/阅读缓存」。
  注意下载目录里的漫画不归缓存管，需要自己去下载目录删。
- **日志**：运行日志在 `data/app.log`，异常堆栈在 `data/error.log`。
